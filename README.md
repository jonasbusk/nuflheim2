# Nuflheim Team Draft List

An unofficial Team Draft List for Blood Bowl.

This project was initialised with `$ npm create vite@latest` and styled with `shadcn/ui`.

## Scope

Nuflheim Team Draft List is a single page application with no server or persistent storage.
The goal is to create a team draft list that is easy to use for anyone familiar with the game and with few restrictions to allow for house rules and experimentation.
